## 协议（每位测试者 ≤10 分钟）
1. 不解释产品，只说"给你个工具，随便查一只你好奇的股票"。
2. 让 ta 出声思考（think-aloud），你录屏 + 录音。
3. 关键要捕捉两个瞬间：
   - **"啊，我懂反方了"** —— 15 大奖藏在这一刻。
   - **"这里看不懂 / 太专业"** —— 直接变成下一步要改的清单。
4. 结束问三句：① 你会不会更谨慎地对待网上的"买入结论"？② 审计标红那条你信吗？③ 你会推荐给同学吗？
