## 1. 解决什么问题 / 目标用户
- **问题**：理财小白面对一个标的，网上只有一边倒的“买入结论”，看不到反方、风险、和“这条论据是不是挑出来的”。
- **用户**：年轻首投者 / 理财小白（含我们自己两名 14 岁）。
- **产品**：反方 · AI 投资辩论庭——多智能体对抗辩论 + 独立审计的理财认知教练，不给买卖、教你判断。

## 2. 人机协作工作流（多智能体协作，占 30%）
**核心自洽**：我们做的产品本身就是“六个 Agent 协作 + 一个独立审计”，而我们**用 Qoder 的多智能体并行开发它**——用一支 AI 团队造另一支 AI 团队。

| Qoder Agent 角色 | 承担的开发工作 | 对应本仓库 | 证据 |
|---|---|---|---|
| 后端/架构 Agent | Agent 编排、A2A 服务、审计逻辑 | `backend/agents.py` `orchestration.py` `a2a_server.py` | TODO 录屏 |
| 数据/技能 Agent | QuantSkills / panda_data 封装、真实 skill CLI 适配 | `backend/skills/*` | TODO 录屏 |
| 前端/产品 Agent | 教练界面、分歧地图、审计印章、人话层 | `web/index.html` | TODO 录屏 |
| 测试/评审 Agent | 全套自动化测试、示例任务回归、代码评审 | `tests/*` | TODO 录屏 |

**人机分工**：人给意图与取舍（选题、合规红线、叙事）；Qoder 多 Agent 并行落地各模块并互相评审；人把关合并。**4 个人干了一个团队的活。**

## 3. 真实价值（25）
- 端到端可运行（离线零凭证即可演示），全套自动化测试全绿。
- 两个真实 QuantSkills 审计器已接入现场辩论，输出带 provenance 可追溯。
- 合规层代码级强制“不给买卖/收益”，对小白负责。

## 4. 创新（15）
- 审计 Agent **独立复核并打回**其他 Agent 的论据（抓选择偏差/坏数据/过拟合）——“AI 拆 AI 的台”是别处没有的协作形态。
- “人话层”把量化审计翻译成小白类比，专业深度与可读性两层并存。
