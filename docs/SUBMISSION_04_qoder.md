# Qoder（参评类别 04）说明

## 项目解决什么问题

股票研究材料常把结论放在最前面，却没有清楚说明反方理由、数据缺口和模型风险。Devil's Committee 让 Bull、Bear、Macro、Risk 四个 Agent 分别阅读证据，Audit Agent 检查选择偏差、数据问题和过拟合，Chair 汇总共识、分歧和风险范围。产品不给买卖指令、目标价或收益承诺。

## 用户是谁

目标用户是想理解股票研究、但不熟悉量化术语的初学者。当前真实研究只支持 A 股；固定示例是 `600519.SH`、`300750.SZ` 和 `601318.SH`。其他市场会返回证据不足，不会用模拟结果代替。

## 人和 AI 怎么分工

人负责确定问题、选择功能范围、制定合规限制、检查技术事实，并决定哪些内容可以公开。AI 负责在明确任务下修改后端、前端、测试和文档，执行本地检查，并把不确定项明确写出。最终是否合并、是否使用真实凭证、是否部署公网服务，以及参评材料中的团队信息和外部链接，都由人确认。

开发中的 Agent 可按代码范围分工，例如接口与编排、PandaData 与 QuantSkills、页面、测试和文档。不同 Agent 的修改必须由人查看差异和检查结果后再提交，不能把 AI 输出直接当成事实。

截图或录屏可以作为补充材料，但不是本说明的必填内容。若使用，只展示仓库里确实存在的过程；团队成员、真实使用方式和工具记录均需人工填写。
