01摘要

当强模型人人可得，结论不再稀缺，判断力才稀缺。市面上的金融 AI 几乎都在生产更好的结论； 我们反转范式：不生产结论，而是编排一场结构化的对抗辩论，并引入一个 独立审计 Agent，在真实历史数据上复核论据的完整性——抓过拟合、选择偏差、坏数据，可当场驳回。

与套壳聊天框的本质区别在于：本系统的每个数字都从真实行情算出来。我们构建了一个真量化引擎， 在 24 只 A 股、726 个交易日上计算真因子的横截面 IC、样本内/外分离与多空回测。审计据此抓出的过拟合是 可复现的真发现，而非预设脚本。产品一个引擎、两张脸：对开发者是标准 A2A Remote Agent， 对小白是不给操作建议、只教判断的理财教练。

02问题

情境：理财小白面对一只标的，网络信息高度一边倒——满屏「买入 / 看涨」，而三样最关键的东西被系统性隐藏：

  • 反方缺席：看多叙事从不认真呈现看空逻辑。
  • 风险被抹平：清仓冲击成本、事件驱动异常收益、持仓集中度，在顺风故事里消失。
  • 论据不可审计：一个「历史回报很高」的因子，可能是过拟合（样本内漂亮、样本外失效） 或选择偏差（只统计了活下来的赢家）的产物——小白无从分辨，甚至专业玩家也常自欺。

03产品概述

用户用一句自然语言提问（如「帮我理解 600519 现在多空双方的理由和风险」），系统返回：一场可读的辩论 （多头/空头/宏观/风控逐条论据 + 证据）、一张分歧地图、每条论据的审计印章、以及明确的风险边界与免责。 全程不给买卖操作、不给目标价、不承诺收益；输出中 gives_investment_advice=false 是可被程序校验的字段。

04真量化引擎（核心差异化）

这是本项目与「AI 套壳」的分水岭：辩论论据不是种子生成的假数字，而是从真实 panda_data 行情实算。 引擎在 24 只 A 股 × 726 个交易日（2022-01 ~ 2024-12）上，对一个因子库计算横截面 rank IC、t 检验、样本内/外分离与多空回测。真实结果如下（诚实到不讨好）：

因子样本内 IC (t)样本外 IC (t)多空夏普最大回撤判定
动量加速+0.047 (3.04)−0.027 (−1.2)0.47−22%⚑ 过拟合
低波动+0.026 (1.73)+0.029 (1.45)0.03−37%稳健
20日动量−0.011 (−0.75)+0.040 (1.94)0.46−18%—
60日动量−0.064 (−4.24)+0.038 (1.63)0.01−36%反转
诚实性即可信度

2022–2024 A 股整体下行，多数动量因子在这段几乎无效（t 值不显著）。我们不掩饰—— 恰恰是这种「连自己多头挑的因子都敢拆」的诚实 + 样本外验证，比任何漂亮的假数字都硬。

审计的回报：不只批评，更改进结果

审计剔除被判过拟合的因子（动量加速），把放行的稳健因子等权合成组合（横截面 z-score）。 对比朴素挑法（样本内最佳 = 过拟合的动量加速）：

策略样本外 IC (t)含义
朴素：挑样本内最佳因子−0.027 (−1.2)样本外预测力为负——被过拟合骗了
审计后：稳健因子合成组合+0.043 (2.02)样本外预测力显著为正——审计让预测真的更可信
↑ 稳健组合多空净值（真实回测，10bps/边成本，换手 0.27）。注：熊市中 IC 转正但绝对收益仍承压——这是诚实的，我们区分「预测力」与「择时收益」。

分层回测与稳定性诊断（因子研究的标准动作）

除 IC/t 检验外，引擎还做量化研究的标准诊断——全部真实计算：

分层回测 · 20日动量 · 5 档平均收益(bps)
顶档(Q5)显著跑赢底档(Q1)，头−尾 +24bps——因子有真实分层能力。

稳定性诊断（真实计算）

滚动 IC（动量加速）：前半期 +0.031 → 后半期 +0.005—— 信号随时间衰减，这正是它样本外崩塌的根源。
因子相关性：库内平均 |corr| = 0.294（低）——因子彼此不冗余， 稳健组合是真的在分散信息，不是重复下注。
IC 衰减：多期限 forward IC（1/3/5/10/20 日）随持有期变化，刻画信号快慢。

05审计方法论：抓假与改进

审计 Agent 是全场唯一「别人没有」的东西。它不信任取证 Agent 的自我陈述，而是独立重新计算并复核：

维度方法（真实计算 / 真 QuantSkills）抓什么
过拟合因子样本内/外 IC 分离 + t 检验（real-quant）样本内显著、样本外崩塌/翻负
坏数据corporate-action-adjustment-auditor（real-cli）真实数据里的未复权除权跳空
选择/存活偏差survivorship-universe-auditor只挑赢家、遗漏退市样本

真实抓假示例（可复现）：

# 过拟合（real-quant，样本外验证）
BULL 挑「动量加速」：样本内 IC=0.047 (t=3.04 显著)
AUDIT 独立跑样本外 → IC=−0.027 (t=−1.2)　⚑ SUSPECTED-OVERFIT　“背答案，不是规律”

# 坏数据（real-cli，真实 QuantSkills 在真实数据上）
300750 宁德时代 → large_unexplained_raw_price_jump　⚑ 未复权除权跳空 −41.8%

每条审计结论带 provenance：real-quant / real-cli / mock-fallback / mock——评委可一眼分辨真算还是启发式，可追溯、不套壳。

06核心机制：对抗辩论（真协作，非串联）

用户提问 → 标的解析
  ├─ BULL  挑样本内最佳因子（真实 IC/IR/回测）  ┐
  ├─ BEAR  真实波动率 / 最大回撤 / 流动性        │ 并行取证
  ├─ MACRO 风格/环境背景                        │ asyncio.gather
  └─ RISK  敞口与合规边界                        ┘
        ↓
  AUDIT（独立复核，可打回） 样本外验证 · 复权审计 · 存活偏差
        ↓
  CHAIR（收敛） → 共识 / 未解分歧 / 风险边界 → compliance.enforce()

四方并行取证（非固定链路）；审计独立复核、可打回。总响应受 18 分钟全局预算 + 每 Agent 超时约束， SSE 流式先吐进度——满足 A2A 赛道「响应 <20min、评审期在线」的硬要求。

可解释性

08合规与稳健性

  • 合规闸：代码级拦截买卖/收益/目标价/荐股，强制风险免责，审计标记可见。
  • 机器可校验立场：gives_investment_advice=false · recommendation=null。
  • 三层降级：单次 LLM 抽风→占位文本；单 Agent 故障→该方不出论据；整场异常→结构化错误不裸崩。
  • 安全：Bearer 常量时间比较、错误脱敏、前端对 LLM 输出 XSS 转义。
