## 1. 目标人群
年轻首投者 / 理财小白——**就是我们自己**（两名 14 岁 + 两名大学生）。特征：看得懂中文、看不懂投顾黑话、最容易被网上一边倒的“买入结论”带跑。

## 2. 痛点 + 依据
- **痛点**：网上关于一个标的的信息几乎只有结论（买这个/涨那个），看不到反方是谁、风险在哪、那条论据是不是被挑出来的。小白没有“当裁判”的工具。
- **依据**：我们两个 14 岁真的看不懂大人的投顾——这不是设定，是团队真身份；我们按自己“第一次想搞懂一只票”的困惑来设计每一句话。

## 3. 引导式逻辑 + 不给答案 + 风险机制（核心）
**引导式**：不直接回答“能不能买”，而是把一场辩论摊开——多头/空头/宏观/风控各自的理由，再由**审计 Agent 当场标出哪条论据站不住**，最后给一张“分歧地图 + 风险边界”。

**人话通道（让小白真看懂反方）**：每条论据、每个审计标红都配一句零术语类比：
- `pass` → 这条经得起查：数据、抽样、调参都对得上，暂时挑不出毛病。
- `selection_bias` → 小心：这像“只把考了高分的同学拿出来吹，输的都不提”——样本被挑过了，看起来的规律可能是假的。
- `bad_data` → 小心：这条用的价格数据本身有问题（好比体重秤没归零就称），先把数据修对，再谈结论。
- `suspected_overfit` → 小心：这像“把这次的答案背下来考试”，换一套题就不灵——不是真规律，是凑出来的。
- `thin_data` → 证据太少：既不能信、也不能一口否掉，先别当真，等更多数据。

**不给答案 —— 实跑证据（audit_claims 输出，标的 600519.SH）**：
整场输出里没有任何“买/卖/目标价/收益”，只有“哪条论据可信、风险在哪”。逐条审计：

- **Bull** 的论据 → 审计判定 `pass`：这条经得起查：数据、抽样、调参都对得上，暂时挑不出毛病。
- **Bear** 的论据 → 审计判定 `bad_data`：小心：这条用的价格数据本身有问题（好比体重秤没归零就称），先把数据修对，再谈结论。
- **Macro** 的论据 → 审计判定 `pass`：这条经得起查：数据、抽样、调参都对得上，暂时挑不出毛病。
- **Risk** 的论据 → 审计判定 `bad_data`：小心：这条用的价格数据本身有问题（好比体重秤没归零就称），先把数据修对，再谈结论。

> 免责声明（每次输出强制附带）：本内容由多智能体辩论生成，仅供学习与研究，不构成任何投资建议；不含买卖操作、目标价或收益承诺。历史/缓存数据不代表未来表现。

**风险机制（代码级强制，非口头承诺）**：所有对外输出经 `backend/compliance.py`，正则拦截 8 类操作性表述——`建议买入/卖出`、`目标价`、`必涨/稳赚`、`收益率 N%`、`荐股`、`strong buy` 等，命中即替换为「〔已按合规移除操作性表述〕」，并标注 AI 不确定项、建议人工/专业核实。
