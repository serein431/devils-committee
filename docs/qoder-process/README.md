## 可保存的真实材料
- [ ] 已有的 Qoder 开发截图或录屏，例如前端 Agent 修改 `web/`、后端 Agent 修改 `backend/orchestration.py`。

## 04 两问回答要点
1. **解决什么问题 / 目标用户**：给理财小白的反方教练（见根 README 六段式）。
